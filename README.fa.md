# WarpEP ساخته‌ی ArJey

**اسکنر واقعی اندپوینت‌های Cloudflare WARP، همراه با پنل کاربری.** هر نتیجه از یک هندشیک
واقعی WireGuard با سرور WARP کلادفلر می‌آید، و اندپوینت‌هایی که برچسب `VERIFIED` دارند،
**قبل از اینکه شما ببینید**، ترافیک واقعی ICMP را از داخل یک تانل واقعی رد و برگشت
کرده‌اند.

بدون هیچ وابستگی. پایتون خالص. روی **ترموکس، ویندوز، مک، لینوکس و WSL** اجرا می‌شود،
بدون نیاز به کامپایل چیزی.

## پنل کاربری

دستور `warpep` بدون هیچ آرگومانی پنل را باز می‌کند. روی همه‌ی سیستم‌عامل‌ها دقیقاً همین
منو را می‌بینید:

</div>

```
--  WARPEP PANEL  ----------------------------------------------

   1. endpoint scan fast              اسکن سریع، حدود ۲۰ ثانیه، پورت ۲۴۰۸
   2. endpoint scan deep              اسکن کامل همه‌ی رنج‌ها و پورت‌ها
   3. endpoint scan IPv6              وقتی IPv4 فیلتر است ولی IPv6 نه
   4. best endpoints for my operator  بهترین‌های اپراتور خودتان
   5. MASQUE scan (TCP / QUIC)        وقتی UDP وایرگارد کامل بسته است
   6. verify one endpoint             تست واقعی یک اندپوینت مشخص
   7. export config                   ساخت کانفیگ WireGuard / AmneziaWG / sing-box
   8. network doctor                  دقیقاً چه چیزی خراب است
   9. WARP account                    ثبت دستگاه خودتان در کلادفلر
  10. settings                        تنظیمات
  11. self test                       تست سلامت برنامه
   0. quit
```

<div dir="rtl">

گزینه‌ی `1` را بزنید. حدود بیست ثانیه بعد یک جدول و یک جواب روشن می‌گیرید.

### معنی برچسب‌ها (مهم‌ترین بخش)

این همان چیزی است که نسخه‌ی ۲ برای آن ساخته شد.

| برچسب | معنی | استفاده کنم؟ |
|---|---|---|
| `VERIFIED` | هندشیک کامل شد **و** ترافیک واقعی ICMP از تانل رد و رمزگشایی شد. | **بله.** این اندپوینت واقعاً کار می‌کند. |
| `ALIVE` | هندشیک معتبر WireGuard انجام شد، ولی تانل تست نشده. | احتمالاً. اول تستش کنید. |
| `RATE LIMITED` | کلادفلر cookie challenge داد. زنده است ولی محدودتان کرده. | سرعت را کم کنید: `--rate 200` |
| `NO TRAFFIC` | هندشیک می‌دهد ولی بسته‌ها را می‌خورد. **همان تله‌ی معروف.** | **نه.** این همان «پینگ خوب، اندپوینت مرده» است. |
| `DEAD` | هیچ جوابی نداد. | نه. |

ابزارهای دیگر بر اساس پینگ مرتب می‌کنند و ردیف اول را به شما می‌دهند. در جدولی که بر
اساس پینگ مرتب شده، یک اندپوینت ۳۰ میلی‌ثانیه‌ای که ترافیک شما را می‌اندازد همیشه از یک
اندپوینت ۱۲۰ میلی‌ثانیه‌ای سالم بالاتر می‌ایستد. WarpEP بر اساس **سلامت (health)** مرتب
می‌کند، `NO TRAFFIC` را عمداً پایین می‌برد، و فقط اندپوینت‌هایی را خروجی می‌دهد که پشتشان
می‌ایستد.

## خط فرمان

</div>

```bash
warpep                            # پنل روی ترمینال
warpep scan --fast                # اسکن سریع، مناسب دیتای موبایل
warpep scan --deep                # اسکن کامل همه‌ی آدرس‌ها و پورت‌ها
warpep scan -6                    # اسکن IPv6
warpep scan --awg                 # فعال‌سازی اجباری مبهم‌سازی AmneziaWG
warpep scan --verify 5            # تست تانل واقعی برای ۵ اندپوینت برتر
warpep masque                     # اسکن MASQUE روی TCP/443
warpep verify 162.159.192.1:2408  # تست واقعی یک اندپوینت
warpep config -o warp.conf        # ساخت کانفیگ WireGuard
warpep config --format amneziawg -o warp-awg.conf
warpep doctor                     # عیب‌یابی شبکه
warpep register                   # ثبت دستگاه خودتان
warpep operators                  # حافظه‌ی هر اپراتور
warpep selftest                   # ۱۴ تست سلامت
```

<div dir="rtl">

خروجی‌ها: `--json` و `--csv` و `-o` (لیست ساده‌ی `ip:port`) و `--links` (لینک‌های
`warp://` برای Hiddify و NekoBox) و `--conf` و `--awg-conf` و `--singbox`.

## چرا WarpEP اندپوینت سالم پیدا می‌کند ولی بقیه فقط دیوار اندپوینت مرده نشان می‌دهند

**۱. با یک هویت ثبت‌شده اسکن می‌کند.** سرور WARP کلادفلر بخش `encrypted_static` را
رمزگشایی می‌کند تا بفهمد چه کلاینتی تماس گرفته، و هندشیک کلیدهایی که **دستگاه ثبت‌شده‌ی
WARP نیستند را بی‌صدا می‌اندازد**. نه جوابی، نه خطای ICMP، هیچ چیز. پس هر اسکنری که با
یک کلید تازه‌ساخته کار کند فقط یک نتیجه می‌تواند بدهد: «همه‌ی اندپوینت‌های دنیا
مرده‌اند». نسخه‌ی ۱ WarpEP دقیقاً همین باگ را داشت و همان چیزی است که شما در تصویر
می‌دیدید. نسخه‌ی ۲ قبل از فرستادن هر پروب یک هویت ثبت‌شده پیدا می‌کند، یکی هم همراه
خودش دارد تا نصب تازه بدون هیچ تماس شبکه‌ای هم درست کار کند، و اگر به زور خلافش را
بخواهید با رنگ قرمز می‌نویسد `enrolled: NO`.

**۲. پیش‌آزمون قبل از قضاوت.** اول اندپوینت‌های کنترلی که مطمئناً جواب می‌دهند تست
می‌شوند. اگر آن‌ها ساکت بودند، مشکل از هویت یا شبکه یا پورت‌های UDP شماست، و WarpEP همین
را می‌گوید، نه اینکه چهار هزار ردیف مرده چاپ کند.

**۳. قیف، نه یک اسکن مسطح.** یک پروب ارزان مشخص می‌کند کی خانه است. بازمانده‌ها چند پروب
دیگر می‌گیرند تا پینگ و جیتر از یک نمونه‌ی واقعی دربیاید. فینالیست‌ها تانل کامل
می‌گیرند: هندشیک، کلید انتقال، ارسال ICMP و رمزگشایی در برگشت.

**۴. جدیدترین تکنولوژی ضد فیلترینگ روی پروب‌ها.** بسته‌های زائد AmneziaWG
(`Jc/Jmin/Jmax`) و بسته‌ی جادویی `I1` (یک پاسخ DNS جعلی برای `icloud.com`) تا جریان با
یک بسته‌ی ۱۴۸ بایتی قابل‌شناسایی WireGuard شروع نشود. خود هندشیک بایت‌به‌بایت درست
می‌ماند، پس جواب گرفتن هنوز ثابت می‌کند اندپوینت واقعی است. اگر فقط پروب‌های مبهم‌شده
جواب گرفتند، یعنی شبکه‌ی شما WireGuard را از روی امضایش می‌شناسد و به کلاینت AmneziaWG
نیاز دارید؛ WarpEP همان کانفیگ را برایتان می‌سازد.

**۵. MASQUE، با اندازه‌گیری واقعی.** جدیدترین ترنسپورت WARP کلادفلر همین است: CONNECT-IP
روی HTTP/3، با یک مسیر جایگزین HTTP/2 روی TCP که روی سیم دقیقاً شبیه HTTPS معمولی است.
WarpEP بخش HTTP/3 را با یک بسته‌ی QUIC version negotiation تست می‌کند (جواب باید
Connection ID های ما را برگرداند، پس یک میدل‌باکس نمی‌تواند جعلش کند) و مسیر جایگزین را
با هندشیک واقعی TCP + TLS + ALPN h2. وقتی UDP کامل بسته است، این راه شماست.

**۶. اپراتور شما را می‌شناسد.** فیلترینگ در سطح اپراتور اعمال می‌شود نه کشور؛ اندپوینتی
که روی ایرانسل عالی است می‌تواند روی مخابرات کامل مرده باشد. WarpEP از خود لبه‌ی کلادفلر
می‌پرسد روی چه ASN هستید، بعد یک حافظه‌ی **خصوصی و محلی** از آنچه واقعاً روی *همان* شبکه
جواب داده نگه می‌دارد و دفعه‌ی بعد اول همان‌ها را تست می‌کند. هیچ چیزی از دستگاه شما
بیرون نمی‌رود.

## وقتی هیچ چیز کار نمی‌کند

`warpep doctor` را اجرا کنید. هویت، UDP، DNS، API وارپ، وایرگارد روی IPv4 و IPv6، اینکه
کدام پورت‌ها بیرون می‌روند، و MASQUE روی TCP و QUIC را اندازه‌گیری می‌کند و در آخر
می‌گوید کدام را باید درست کنید.

راه‌حل‌های سریع:

- همه `DEAD` و در هدر نوشته `enrolled: NO` -> `warpep register`
- اندپوینت‌های کنترلی ساکت ولی MASQUE جواب می‌دهد -> `warpep masque`
- پورت‌های پیش‌فرض بسته -> `warpep scan --ports all`
- IPv4 فیلتر است -> `warpep scan -6`
- همه `RATE LIMITED` -> `warpep scan --rate 200 -c 2`
- کادرها به‌هم‌ریخته -> `WARPEP_ASCII=1 warpep`

فایل‌ها در `~/.config/warpep` ذخیره می‌شوند (در ویندوز `%APPDATA%\WarpEP`) و با
`WARPEP_HOME` قابل تغییر است. هیچ چیزی جایی آپلود نمی‌شود.
